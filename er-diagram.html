🔗 表间关系（基数）

关系基数实现方式
MEMBER — UNIT（成员所属分队）N : MMEMBER.units[] → UNIT.id（多值外键）
PLACE — UNIT（地点所属分队）N : MPLACE.units[] → UNIT.id
PLACE — MEMBER（地点与成员同款）N : MPLACE.members[] → MEMBER.id
PLACE — TYPE（地点类型）N : 1PLACE.type → TYPE.type
PLACE — CATEGORY（地点分类）N : 1PLACE.category → CATEGORY.category
PLACE — STATION（最近地铁站）N : 1PLACE.station 文本 → TRANSIT.resolveStation()
CUSTOM_PLACE — PLACEIS-A继承地点全部字段，custom=true 区分
LINE — STATION（线路经停站点）N : M关联实体 LINE_STOP（line_id + station_id + seq）
STATION — STATION（相邻站）1 : N派生 STATION_EDGE（含线路族，用于耗时/换乘）
ROUTE_PLAN — PLACE（勾选地点）N : Mselected[] / order[]
ROUTE_PLAN — STATION（出发站）N : 1origin_station（地址→最近地铁站）
ROUTE_PLAN — TRANSIT_LEG（生成行程段）1 : N每段含 via_stations、换乘、气候卡标注
