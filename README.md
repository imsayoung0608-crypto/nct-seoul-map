# NCT 首尔同款地图 💚

一个以**地图**形式收集 **NCT（含 NCT 127 / NCT DREAM / WayV / NCT WISH）** 首尔**同款店铺**与**拍照打卡点**的静态网站。

## 功能
- **交互地图**：基于 Leaflet，所有地点以图钉标注，点开可见详细信息；粉丝自建地点使用不同颜色图钉；地图底图支持 **OSM / Carto / OSM France / Esri 多图源自动切换**（某图源加载失败或网络不通时自动换源，国内手机也能正常显示）
- **成员标注**：每个地点都标注了「哪位/哪些成员」去过（如：在玹&道英、泰容生日聚会、辰乐叔叔的店）
- **搜索**：输入成员名 / 分队名 / 店铺名 / 地铁站等即可筛选（支持中、英、韩文别名，如「泰容」「taeyong」「태용」）
- **筛选**：
  - 分队多选（NCT 全体 / 127 / DREAM / WayV / WISH）
  - 成员多选（含任意所选成员的地点）
  - 分类（同款店铺 / 拍照打卡点）与类型（美食 / 咖啡 / 拍摄地…）多选
- **地点列表**：侧栏/底部卡片与地图联动，点击卡片自动定位
- **已退团成员标注**：已退团成员（Mark、昀昀）单独前往的地点已从地图移除；与他人同去的地点保留并标注「已退团」（昀昀曾属 NCT 127 与 WayV，两处分组均已标注退团）；文泰一相关词条已按用户要求整体删除；成灿已从成员列表与全部词条中删除
- **多队成员标注**：跨分队成员（如楷灿、Mark 同时属于 NCT 127 与 NCT DREAM）在每个所属分队分组下都会出现；勾选其中任意一个，其他分组的同名成员会自动同步勾选（不会重复选择）
- **路线规划（公共交通）**：开启「开始选点」后，可先填写**出发地址/附近地铁站**（自动匹配最近地铁站，也可留空从第一个地点出发），再勾选多个地点 → 点击「规划最优路线」→ 系统基于内置首尔地铁网络计算站间耗时与换乘（Dijkstra + TSP/2-opt 求最优访问顺序），在地图上画出路线并生成每段的：线路、换乘次数、地铁时间、步行时间、**气候卡可用性标注**与 Naver Map 公交/App 导航链接
- **气候卡标注**：依据 Naver Map 标注的交通信息，逐段标注「✅ 全程可用气候卡（首尔市内）」或「⛔ 含气候卡不可用路段（超出首尔市界，如富川、河南渼沙等）」
- **自定义地点**：内置「➕ 添加地点」系统——用户可自行输入地点名称/地址，若网站中没有则自动添加；补充信息（韩文名、地铁站、分类、类型、坐标、分队、成员、备注、来源）由用户手动填写，保存后同步显示在地图与列表中（保存在浏览器本地，可一键导出 JSON 备份）

## 使用方式
直接双击打开 `index.html` 即可（需要联网加载地图瓦片与 Leaflet），或在项目目录启动任意静态服务器后访问。

## 数据说明
- 所有坐标均为**约略值**，仅用于地图展示；实际导航请以 Naver Map / 谷歌地图为准
- 信息来自粉丝社区公开整理（韩游网、Creatrip、oshito、NOL World、16fan、**小红书 / Lemon8 粉丝打卡帖**、starsofheavens、whatmytrip、PopDaily、FanWork、Trip.com、mydaily、**Visit Korea 官方 K-POP MV 巡礼路线**等），每条目附有 `source` 来源链接
- 快闪/展览类（如 WISH《Ode to Love》快闪、20世纪印刷事务所特展）可能已结束，条目中有标注
- 欢迎把你知道的新地点补充进 `js/data.js`（复制一条记录，填好 `name/nameKo/units/members/addressKo/station/lat/lng/source` 即可），或直接使用页面内的「添加地点」功能

## 路线规划说明
- 站间耗时按每站约 **2.5 分钟**、换乘按 **6 分钟**估算，非实时公交时刻表，仅供参考，请以 Naver Map 实时公交为准
- 气候卡（기후동행카드）适用：首尔市界内 1~9 号线、支线、盆唐/京义中央/机场铁路（一般）等路段；**超出首尔市界**（如富川、河南渼沙等）或机场快线直达/高速巴士**不可用**——按 Naver Map 标注在结果中逐段标识
- 每个停靠点附有 **Naver Map 公交路线链接**（网页版）与 **Naver App 公交导航链接**（手机端），可点开查看真实公交方案

## 发布到公网（让其他人也能访问）

本网站是纯静态站点，不需要服务器，任选一种方式即可公开访问：

### 方式一：Netlify Drop（最快，无需注册，约 1 分钟）
1. 打开 https://app.netlify.com/drop
2. 把本目录（或解压后的 nct-seoul-map 文件夹 / zip）直接拖进网页
3. 稍等片刻会生成一个公网地址，形如 https://xxxx.netlify.app ，把链接发给别人即可打开
> 提示：无需账号也能用；想长期保留可免费注册后绑定

### 方式二：Gitee Pages（国内访问更稳，需免费注册）
1. 在 https://gitee.com 注册并新建仓库，把本目录文件上传
2. 仓库 → 服务 → Gitee Pages → 启动（选择部署分支与目录 / 或根目录）
3. 得到 https://用户名.gitee.io/仓库名/ 公网地址
> 需要实名认证后 Gitee Pages 才能生效

### 方式三：GitHub Pages（全球通用，需注册）
1. 在 GitHub 新建仓库并上传本目录文件
2. 仓库 Settings → Pages → 选择分支（main / 根目录）→ Save
3. 得到 https://用户名.github.io/仓库名/

### 方式四：Vercel / Cloudflare Pages
- Vercel：https://vercel.com → New Project → Import 仓库（或 CLI 上传）
- Cloudflare Pages：https://pages.cloudflare.com → 拖入文件夹即可

> 说明：地图底图已内置多图源自动切换（OSM → Carto → OSM France → Esri），任何网络的访客都能正常看到地图；坐标约略值，导航请以 Naver Map 为准。
